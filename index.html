1. Overview

GEO Auditor is a free Chrome extension that estimates the likelihood of a web page being cited by AI-powered search engines (ChatGPT, Perplexity, Gemini, etc.). It produces a score out of 100 across five dimensions and generates actionable recommendations.

We do not collect personal information, track your browsing, or sell any data. The extension operates on an explicit opt-in basis: analysis only starts when you press "Analyze".

2. Data Collection

Data collected on demand (when you click "Analyze"):

  • The domain name of the active tab (e.g. example.com)
  • The visible text content of the active page (used for semantic analysis via the Groq API)

Data never collected:

Audit results (score, sub-scores, recommendations) are saved in chrome.storage.local — they stay on your device and are never uploaded.

3. Data Processing

When you click "Analyze", data flows as follows:

  1. The extension reads the active page's domain and text content.
  2. The domain is sent to authority APIs (OpenPageRank, SerpAPI for Perplexity citations, Reddit, Wikipedia) to compute the Authority Signal score.
  3. The page text is sent to the Groq API (via the proxy) for semantic analysis.
  4. All responses are combined locally by the extension to compute the GEO Score.
  5. Results are displayed in the side panel and saved to local storage.

No data is processed in the background. The extension is inactive until you explicitly trigger an analysis.

4. Score Calculation

The GEO Score is a weighted average of five dimensions, each scored 0–100:

DimensionWeightWhat it measures
Authority Signal30 %Domain reputation as seen by AI systems — PageRank, backlinks, citations on Perplexity, Reddit mentions, Wikipedia references
Extractability25 %Ability to extract direct answers — answer clarity, factual density, heading structure, readability
Answerability20 %Question/answer structure, FAQ presence, structured data, Q&A format
Crawlability15 %AI crawler accessibility — robots.txt directives, llms.txt presence, noai directives
Semantic Coverage10 %Semantic depth, named entities, thematic coherence

Authority Signal sub-breakdown (out of 100):

OpenPageRank (PageRank integer)45 pts0–1 → 0–10 · 2–3 → 10–22 · 4–5 → 22–35 · 6+ → 35–45
OpenPageRank (external backlinks)5 pts<100 → 1 · <1k → 2 · <10k → 4 · 10k+ → 5
Perplexity citations (via SerpAPI)22 pts0 → 0 · 1–2 → 8 · 3–5 → 13 · 6–10 → 18 · 11+ → 22
Reddit mentions16 pts0 → 0 · 1–2 → 5 · 3–5 → 10 · 6–10 → 13 · 11+ → 16
Wikipedia references12 pts0 → 0 · 1–2 → 5 · 3–5 → 8 · 6–10 → 10 · 11+ → 12

5. Data Storage

On your device: Audit results (scores, recommendations, analyzed URL) are stored in chrome.storage.local. They persist until you clear the history from the History tab or uninstall the extension. They never leave your device.

On our servers: None. The Cloudflare Worker proxy processes requests in memory only. No logs, no database, no persistent storage server-side.

7. User Consent

A consent screen is displayed at first launch, before any data collection occurs. By clicking "I agree — Start using GEO Auditor", you consent to the data processing described in this policy.

You may withdraw consent at any time by uninstalling the extension. All locally stored data is deleted upon uninstallation.

8. Offline Mode

You can enable Offline Mode in Settings at any time. When enabled:

  • No data is sent to any external API.
  • Only local analysis is performed (Semantic Coverage, Extractability, Answerability, Crawlability).
  • The Authority Signal dimension is unavailable (marked N/A).
  • An "OFFLINE" badge is displayed in the header.

10. Third-Party Services

Each third-party service listed above operates under its own privacy policy. GEO Auditor does not control how those services handle the domain data they receive. All requests are routed through the Cloudflare Worker proxy to avoid exposing API keys in the extension code.
