Privacy Policy

GEO Auditor — Chrome Extension

Last updated: March 2026  ·  Extension version: 1.0.0  ·  Contact: geo-auditor@proton.me

Overview

GEO Auditor is a free Chrome extension that analyzes the active web page to evaluate its GEO (Generative Engine Optimization) score — its potential to be cited by AI search platforms such as ChatGPT, Gemini, Perplexity, and Claude.

This Privacy Policy covers how the extension collects, processes, stores, and shares data, in accordance with the Chrome Web Store Developer Program Policies.

GEO Auditor does not collect personal information, does not track browsing activity, and does not sell or share data for advertising or commercial purposes.

1. Data Collection

GEO Auditor collects two categories of data, strictly limited to what is necessary for the audit function:

1.1 Page content data

When the user triggers an audit, the extension reads the following from the active web page:

  • The page URL and domain name (e.g., example.com)
  • The visible text content of the page (headings, paragraphs, up to 50,000 characters)
  • Structured data present on the page (JSON-LD schemas: Article, FAQ, HowTo, Organization, etc.)
  • HTML meta tags (description, robots, og:title, etc.)
  • The contents of /robots.txt and /llms.txt files on the audited domain

This data is collected only on explicit user action (clicking the audit button). The extension does not read pages passively or in the background.

1.2 Audit history

The results of completed audits (score, metrics, URL, timestamp) are saved locally in the browser to allow the user to review past audits. No personal information is included in this history.

1.3 What is NOT collected

  • Personal information (name, email address, physical address)
  • IP address or device identifiers
  • Browsing history or navigation patterns
  • Cookies, session tokens, or authentication data
  • Form inputs or passwords
  • Financial or payment information
  • Any data from pages not explicitly audited by the user

2. Data Processing

Data collected during an audit is processed for the sole purpose of computing the GEO score and generating recommendations. Processing occurs in two steps:

2.1 Local processing (on-device)

The following metrics are computed entirely within the browser, without any data leaving the device:

  • Machine Readability — heading structure, meta tags, schema presence
  • Crawlability — robots.txt and llms.txt directives
  • Fact Density — text length, heading ratio, structural signals

2.2 Remote processing (via proxy)

The following metrics require calls to external APIs, relayed through the publisher's Cloudflare Worker proxy:

The proxy does not perform any additional processing on the data. It acts solely as a secure relay to protect API keys from being exposed in the extension code.

All API responses are used exclusively to compute metric scores and are discarded immediately after the audit is complete.

3. Data Storage

3.1 Local storage (browser)

Audit results are stored locally using the Chrome storage.local API. This data:

  • Remains exclusively on the user's device
  • Is never synchronized to external servers or cloud services
  • Is accessible only to the GEO Auditor extension
  • Can be deleted at any time from the extension's history interface
  • Is automatically removed when the extension is uninstalled

3.2 Proxy (Cloudflare Worker)

The Cloudflare Worker proxy does not store any data. It receives a request, forwards it to the relevant API, and returns the response. No logs, databases, or caches are maintained by the proxy.

3.3 Data retention

Local audit history is retained indefinitely until the user manually deletes it or uninstalls the extension. No data is stored on external servers beyond the duration of a single API request (typically under 2 seconds).

GEO Auditor does not sell, rent, or trade user data. Data sharing is limited strictly to what is necessary for the extension to function:

4.2 No sharing for advertising or analytics

Data is never shared with advertising networks, analytics providers, data brokers, or any party for purposes other than computing the audit score described above.

4.3 No sharing with other users

Audit results are private and stored only on the user's device. They are never shared with other users of the extension or with the publisher.

4.4 Legal disclosures

The publisher may disclose data if required to do so by law or in response to valid legal process (e.g., a court order). Given that no personal data is retained by the publisher, such disclosure would be limited to information about the extension's general functionality.

6. User Rights

In accordance with GDPR and applicable data protection laws:

  • Right of access: audit history is visible directly in the extension interface
  • Right to deletion: clear your history at any time from the extension interface; uninstalling the extension removes all locally stored data
  • Right to object: uninstall the extension to stop all data processing immediately

As the publisher does not collect or retain personal data, requests for data portability or rectification are not applicable.

7. Children's Privacy

GEO Auditor is intended for web professionals and developers. It is not directed at children under the age of 13. The extension does not knowingly collect any information from children.
