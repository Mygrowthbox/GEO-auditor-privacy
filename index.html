1. Overview

GEO Auditor is a free Chrome extension that analyzes the active web page to compute a GEO (Generative Engine Optimization) score — a measure of how likely the page is to be cited by AI search platforms such as ChatGPT, Gemini, Perplexity, and Claude.

This policy explains what data is collected, how it is processed, where it is stored, and with whom it is shared — in compliance with Chrome Web Store policies and GDPR.

GEO Auditor does not collect personal data, does not track your browsing activity, and does not sell any data to third parties — ever.

2. Data Collection

3. Data Processing

Collected data is used exclusively to compute the GEO score of the page you chose to analyze. The processing pipeline is:

  1. The domain is sent to the publisher proxy to query authority scoring APIs (OpenPageRank, SerpAPI, Reddit, Wikipedia)
  2. The page text is sent to the publisher proxy, then relayed to Groq AI for semantic analysis
  3. All API responses are combined by the extension to produce the GEO score
  4. The score and recommendations are displayed to you and saved locally
Data is processed only on demand (when you trigger an audit) and is never processed in the background.

Data is not used for advertising, profiling, or any purpose other than computing your GEO score.

4. Data Storage

4.1 Local storage (your device)

Audit results are stored in chrome.storage.local — a sandboxed browser storage accessible only by GEO Auditor. This data:

  • Remains exclusively on your device
  • Is never synchronized to external servers
  • Can be deleted at any time from the extension interface
  • Is automatically deleted when you uninstall the extension

4.2 Server-side storage

No data is stored server-side. The publisher proxy (Cloudflare Worker) processes requests in memory and discards all data immediately after responding. No logs, no databases, no persistent storage.

4.3 Retention period

Local audit history is retained until you clear it or uninstall the extension. No automatic expiry is applied.

6. User Consent

On first launch, GEO Auditor displays a consent screen that lists all data collected, where it goes, and why — before any analysis begins. You must explicitly click "I agree — Start using GEO Auditor" to proceed.

No data is collected or transmitted before this consent is given.

You can withdraw consent at any time by uninstalling the extension. Uninstalling also removes all locally stored audit history.

7. Offline Mode

GEO Auditor offers an Offline mode accessible from the Settings tab. When enabled:

  • No data is sent to any external API (Groq, OpenPageRank, SerpAPI, Reddit, Wikipedia)
  • Only local on-page analysis is performed (structure, readability, crawlability)
  • The Authority Signal dimension will show as unavailable
  • An "OFFLINE" badge is displayed in the extension header

Offline mode gives you full control over what data leaves your device.

9. Third-Party Services

Each third-party service used by GEO Auditor operates under its own privacy policy (linked in Section 5). GEO Auditor is not responsible for the data practices of these services beyond what is described in this policy.

All third-party requests are routed through the publisher proxy to avoid exposing API keys in the extension code. The proxy does not add any data to the requests beyond what is described above.
